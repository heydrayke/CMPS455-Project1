# CMPS455-Project1
Gained in-depth multi-threading programming experience in Java or C++ by solving the classic Dining Philosophers and Readers-Writers synchronization problems using only semaphores. Gained hands-on experience measuring runtime performance across varying thread counts and parameters, and documenting findings through detailed analysis.


To compile and run from command line:
####
    1.) javac *.java
        (compile program and classes)
####
    2.) java Main.java
        (default that runs both tasks)
####
    3.) java Main.java -A 1
        (runs Task 1: Dining Philosophers)
####
    4.) java Main.java -A 2
        (runs Task 2: Readers-Writer Problem)
